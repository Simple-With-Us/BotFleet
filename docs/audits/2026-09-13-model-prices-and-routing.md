# BotFleet Model And Pricing Audit — 2026-09-13

This is a bounded, read-only audit of the model IDs and transports exposed by BotFleet.  Prices below are official USD per 1M tokens retrieved 2026-09-13, unless marked as unavailable.  Subscription and OAuth products are reported separately because their quotas do not establish API token prices.

## Dominated Or Stale Rows To Flag

- `gpt-5.4` and `gpt-5.4-mini` were retired from Codex ChatGPT sign-in on 2026-08-31 according to the official Codex model guidance.  `o3` and `o3-mini` were present only in the pre-refresh BotFleet static fallback and have no current local app-server evidence here.
- `gpt-5.3-codex-spark` is not API-supported in the local cache and is a text-only CLI specialty.  The API's separately priced `gpt-5.3-codex` must not be presented as the same model.
- Anthropic API `claude-fable-5` is behind current `claude-fable-5-1`, while the apps gateway may intentionally retain an app-specific Fable 5 alias.
- `deepseek-v4-flash` is now a compatibility alias for `deepseek-flash`; BotFleet's DeepSeek price table carries peak/off-peak ranges.
- Antigravity effort suffixes, Cursor subscription labels, and Kimi Code prefixes are transport-specific aliases.  A provider API price must not be inferred from them.

For a current picker, resolve dynamic catalogs at runtime and display transport beside each row: `Codex OAuth`, provider API/BYOK, or subscription CLI.  The shortlist can expose Terra/Sol/Luna/Astra for Codex; Sonnet/Opus/Haiku for Anthropic; M2.7/M3 for MiniMax with cost and context labels; DeepSeek Flash/Pro with peak/off-peak labels; and Composer 2.5 only on Cursor.
