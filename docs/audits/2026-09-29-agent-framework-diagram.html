Every wake converges, then pays twice for the same context

Six ingress paths collapse into one durable queue with layered backpressure, and the reliability work there is better than Grok Bot's documented trigger layer. The cost work is missing: the harness splits its prompt into a stable prefix and then never asks for the cache, and it has no compaction at all.

What works

The trigger layer

Dedupe is checked before the rate limit and flushed durably before the 202. A webhook storm folds into one turn instead of a hundred conversations. The doomed-dispatch breaker declines a dead engine without failing the run, so it still lands after the TTL.

Biggest lever

No cache directive

grep -rn cache_control returns zero hits. The harness already splits the prompt into a byte-identical stable prefix and already ships promptBytes telemetry to check whether the prefix cached — it simply never asks the provider for the discount. That is a missing flag, not a design decision.

Cost floor

No compaction

  • 40-message tail, hard cut, never summarized
  • Thread reuse makes this permanent, not transient
  • Tool results appended verbatim; bash has no byte cap
