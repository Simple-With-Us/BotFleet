## Native Boundaries And Remaining Gaps

- `CodexAppServerRunner.swift`, `AcpProcessRunner.swift`, `ClaudeStreamRunner.swift`, `EngineDriver.swift`, and `EngineReplayHarness.swift` contain the native protocol work for Codex early-tool replay protection, Grok authentication/model selection, and Claude ToolSearch.  `EngineCoordinatorActor` prepares connected-app tools before dispatch and routes provider-limit/quiet outcomes through recovery.  Prepared MCP context on `TurnInput` is excluded from Codable wire encoding and remains trusted in-process state.  The Swift package tests and unsigned BotFleetMac build passed.
- `NativeTurnTools.swift` provides identity-scoped catalog preparation, aliases, schema compaction, the combined tool cap, and local-only MCP mount serialization.  Coordinator wiring is present, but a production mount provider is still an injected interface.
- `NativeEventWaitRegistry.swift`, `NativeRuntimeServices.swift`, `DatabaseService.swift`, and `NativeCompanionServer.swift` provide persisted typed waits, permanent IDs and a timestamped dispatch ledger, a SQLite claim-before-dispatch CAS, monotonic terminal/accepted fences, and per-wait asynchronous dispatch tasks so one follow-up cannot block polling.  Recovery holds ambiguous accepted work rather than replaying it, and opt-in authenticated routes list/register/cancel waits.  The runtime verifies registered bot/thread ownership and prompt bounds; cancellation verifies the scheduler's post-await result is actually cancelled.  Listener stop closes only the network listener; the injected runtime remains caller-owned.  File probes require an injected workspace source, process completion requires an injected ownership source, and the bot-idle probe reads registered bots and dispatcher activity.
- The wait runtime is not active in the app composition: `MacSession` still constructs `NativeCompanionServer(database:)` without a `NativeRuntimeServices` value, so the new routes remain unavailable and no wait polling starts by default.  The server starts polling only when a runtime is explicitly injected and its listener starts.
- The native runtime cutover has not happened.  Preserve BotFleet's standalone Mac app and independently functional Linux backend.
- A TypeScript Composio worker session-isolation port verifies the returned user, scopes cached matches to a stable owner, uses owner/active/previous-session D1 compare-and-swap with post-await rereads, and reuses legacy cached sessions using fresh persisted upgrade metadata.  This does not add an adoption feature or move the worker into Swift.  Its 17 tests and `brokercheck` passed.  The existing Wrangler configuration is explicitly non-deployable and retains placeholder D1 namespace names; no Cloudflare deployment or namespace provisioning was performed.
- #3779 adds only generic MCP exact-address HTTP transport in Swift.  There is no native Box driver or credential broker, and cloud sync is absent.
- There is no native local-model driver, so upstream local-model waiting changes are not yet applicable.  Do not probe arbitrary endpoints or credentials to simulate one.
- Claude tool search is implemented as a private preference read and runner setting; own-file approval behavior is not ported.
- `NativeMCPHTTPClient.swift` supplies a bounded URLSession transport that refuses redirects and ambient credentials/cookies; the catalog actor accepts this client through its transport interface.  The Mac test suite passed.  No live MCP endpoint was contacted.
