## Token Cost And Context

| Finding | Evidence | Action |
|---|---|---|

The maximum replay reduction depends on actual message sizes and tool-round counts; neither was sampled.  The 128 KiB cap bounds **prior text replay**, not the new prompt, system instructions, tools, images, or provider-native sessions.  A 40-message cap alone offered no byte bound.

The broader audit also ranks per-turn checkpoint `git add .` and ever-growing shadow repos (HS24), transient retry gaps in ACP/Antigravity (DR2), and Antigravity's process-wide mutex (DR4) as meaningful latency or wasted-attempt risks.  Their remedies need focused behavior tests; a retry must not blindly duplicate a side-effecting tool call, and the mutex cannot be shortened until `agy`'s MCP-config read timing is verified.  Its severity labels are source-audit prioritization, not measured cost savings.

The broader audit's remaining P0 operations findings are tracked without treating this Mac's overloaded state as a cleanup window: APNs transport log/circuit failures (board `55c8fd23`, issue #576), the process-local refused-key latch and misleading phone health (board `82510efe`, issue #577), and stale transcript files that are capped per thread but never reclaimed (board `4e5b7bb6`, issue #578).  The owner must verify or rotate the refused APNs signing key separately; code can only stop resending it and report the fault accurately.

| GPT-5.5 | $5 / $0.50 / $30 | Keep for saved selections or an evidenced specialty.  Its listed API input and output prices exceed 5.6 Sol, and no comparative BotFleet outcome evidence currently justifies recommending it for routine coding. |

At the source baseline, BotFleet's static fallback at `server/drivers/codex-catalog.ts` defaulted to **GPT-6 Luna** and listed GPT-6 Sol/Luna plus GPT-5.3 Codex Spark, but omitted GPT-5.6 Sol/Luna.  GPT-6 Sol/Luna have direct API prices, yet this Mac's Codex OAuth catalog did not expose them; the fallback default could therefore be unavailable after a catalog timeout.  Board `16e1afdb`, issue #552 tracks the correction in a separate CODEX lane while peer picker PR #539 remains open.  A provider's direct-API alias, including any `_latest` slug, must not be substituted into a CLI/OAuth picker without verifying that exact transport.  Keep a legacy selection round-trippable, but report unavailability rather than silently routing it elsewhere.

The rational default depends on task quality, completion attempts, tokens consumed, and provider quota, not list price alone.  A cheap model that needs repeated failed attempts can cost more than a stronger one.  No BotFleet-specific comparative eval was completed in this pass, so the ranking above is an economic hypothesis, not a measured quality verdict.  The analogous Claude Code version gate is issue #554: installed CLI 2.1.276 predates the [documented 2.1.280 minimum](https://code.claude.com/docs/en/model-config) for Opus 5.5, so `opus` is not yet a safe Opus 5.5 label on this Mac.  DSH's canonical Flash name belongs to the Harness package; issue #560 tracks its dependency update without editing BotFleet's imported model shape.

`latest` semantics are provider- and transport-specific.  [xAI](https://docs.x.ai/developers/models) documents `<modelname>-latest` for its API, while the installed Grok Build CLI enumerates concrete 4.7/4.6/4.5 choices.  [Google](https://ai.google.dev/gemini-api/docs/models) documents hot-swapped `gemini-*-latest` aliases for the Gemini API, but Antigravity's effort-suffixed CLI IDs are a separate catalog.  [Anthropic](https://platform.claude.com/docs/en/about-claude/models/model-ids-and-versions) says newer dateless Claude IDs are pinned versions, not evergreen pointers; older short API aliases target the newest dated snapshot within that minor version.  A direct-API alias can be useful as an explicit follow-latest choice, with a visible resolved model for costs and replay, but no alias should cross into CLI/OAuth selection without verification.
