## Scope And Method

The owner asked for a look at the official DeepSeek Harness (the product page at deepseek.com/en/harness and the deepseek-ai/deepseek-harness repository): what changed since BotFleet integrated it, and which features we are not using that could be built into BotFleet or into the owner's own Harness app, which will be renamed Clutch.

Eight readers each took one slice of the official tree and compared it with BotFleet and Harness.  A second round of six gap readers then covered what the first round skipped or got wrong: the web tools layer, the profile each Clutch launcher really boots, outbound data, the MiniMax route on 0.2, the terminal and interaction packages, and context and utility leftovers.  Every candidate then went to an adversarial verifier that re-read the cited source in all three trees and corrected status, value, size or target where the reader was wrong.  Where the reader and the verifier disagree, this document follows the verifier.  Candidate ids use the reader prefixes below, so ACP-1 means dsh-acp-sdk-api-1 and WEB-8 means gap-dsh-web-tools-layer-8.

## Executive Summary

1. **The version gap is large; the protocol gap is not.**  Upstream went from 0.1.5-rc.2 (Sep 10) to dsh-v0.2.0-rc.2 (Sep 29) through eight prereleases, touching 9,259 files (+1.32M / -161k lines), and npm `latest` now resolves to 0.2.0-rc.2.  The ACP package changed only in type-level ways, so BotFleet's driver should keep working.  The danger is in configuration, state and defaults.
2. **Do not bump the pin until three gates are in place.**  The session-log contributor now uploads the unaccepted session log (up to 8 MiB per request) to the official DeepSeek API by default, and neither telemetry env switch turns it off; only a `session-log-deepseek` patch row does.  `~/.dsh/settings.yaml` is imported once into whichever profile boots first and then renamed.  Sessions convert to format V4, which 0.1.5-rc.2 cannot read back.  Each has a cheap mitigation (below), and the whole jump should be rehearsed under an isolated DSH_HOME first.
3. **Several things are broken or exposed today, with no upgrade involved.**  `~/apps/harness-runtime` points at the deleted `~/Code/Harness` tree (the repo now lives at `~/Code/Clutch`), so the Shellular deepseek and minimax entry points cannot spawn and pm2 harness-web will fail on its next restart.  (`~/apps/dsh-runtime`, which BotFleet's DSH bots use, failed with MODULE_NOT_FOUND in the first round but answered `dsh --version` with 0.1.5-rc.2 at the end of the gap round, after its node_modules were rewritten at 7:46 PM CT.)  Clutch's `scripts/sync-profiles.ts` throws ERR_FS_EISDIR on any profile holding `node_modules`.  The Clutch phone bridge passes a `--resume` flag that headless dsh never had, so phone-thread resume cannot work.  And at the pin, a confirmed thumbs rating or `/feedback` in the Clutch web UI uploads the whole session to a DeepSeek collector, MiniMax turns included, because no launcher sets `DSH_TELEMETRY_DISABLED`.
4. **Clutch policy was aimed at a profile nobody boots.**  `start-web.sh` runs `harness.sh web`, so the tailnet instance is the dsh-owned `web` profile; the tracked `src/profiles/dsh-web` and `mmh-web` are never launched.  Web-only rows go in a tracked `--patch` overlay passed from start-web.sh, machine-wide rows in the home patch `$DSH_HOME/cordis.patch.yml`, and acp rows in an overlay written by the Harness driver.
5. **A stale premise is costing BotFleet code and secrets hygiene.**  Stock dsh-acp has mounted `session/new` mcpServers natively since 0.1.2.  BotFleet's `dsh-acp-bridge.ts` and the YAML overlay (which writes comms, control and Composio tokens to a temp file) exist only because #443 claimed otherwise.  Retiring them also unlocks the biggest DSH reliability lever: one warm dsh process per bot instead of a 200-plugin cold boot every turn.
6. **The best borrows for BotFleet are not DSH-specific.**  A per-turn changed-files card built on the checkpoints BotFleet already takes; a bash tool that kills the process tree and keeps partial output on timeout; an FTS5 index for thread search (the verifier timed the current LIKE scan at 2.7 to 9.3 s on the live 307 MB messages.db, synchronously on the harness event loop); and a Seatbelt write-confined shell for workspace-only bots.  Next in line is a bounded `web_fetch` for HTTP-lane bots (MiniMax, OpenAI-compatible, Grok API), the only engines that cannot read a URL today; DSH's SSRF-pinned transport and its tests are the part worth copying.
7. **For Clutch, most UI gains arrive free with the bump, because Clutch serves upstream's web UI in a shell.**  Clutch's own work is profile hygiene (a launch map and dump-config CI gate, settings expressed as patch rows, a policy overlay for the acp profile), a real phone bridge, and closing exposure: a default-on user terminal and plugin installer behind the tailnet pairing cookie, the feedback upload, and a phone path that runs danger-full-access with nothing else gating it.

## Version Gap And Upgrade Risks

Release path from the pin: 0.1.6-alpha.1 and alpha.2 (Sep 15 and 17), 0.1.5-rc.3 (Sep 22, same dependency set as rc.2), 0.1.7-alpha.1 and alpha.2 (Sep 22), 0.1.7-rc.1 and rc.2 (Sep 23 and 24), 0.2.0-rc.1 (Sep 28) and 0.2.0-rc.2 (Sep 29).

What changed that matters:

- **Behaviour and defaults (0.1.6-alpha.1 and alpha.2):** DeepSeek over the Messages API only; MCP client moved to the official SDK v2 (probe spawn, resource tools); PTC and workflow rows renamed without aliases; plugin manager; web user terminals; session-log upload switched on by default; reduced startup waits; headless gains `--json`, `--session-id` and stdin task input (0.1.6-alpha.1, per MM-08).
- **State (0.1.7-alpha.1 and rc.1):** session format V4; `settings.yaml` retired in favour of per-profile patch rows with a one-time import; directory agent presets replaced by bundle-declared presets; the web profile moves per-session tools, compaction and jobs inside agent presets.
- **Packaging (0.1.7-rc.2 to 0.2.0-rc.2):** schedule, voice input, agent team and auto review shipped as optional bundles; pi-ai 0.87.1 catalog; `--dump-config-schema`; dsh command bundled with Desktop.
- **Unchanged (RC-5, EP-5, FH-6):** the ACP wire (session/new, resume, close, list, set_config_option for model and reasoning_effort, the opaque `[provider, model]` value, allow-once and reject-once), `--profile acp`, `--patch` overlays and the dsh-mcp-client row schema, `.credentials.yaml` handling, the `dsh web:` launch line and web flags, and every row id the Clutch headless patches target except `settings`. ### Recommended Upgrade Sequence

5. **Rehearse in `~/.dsh-trial`** with the candidate installed into a scratch runtime directory at an exact version (never npx).  Fix BotFleet's DSH_HOME join bug first (X8), or the trial silently reads the static catalog.
6. **In the trial:** run `dsh --profile <name> [--patch <overlay>] --dump-config` for the profiles that actually boot: web (with the U6 overlay), acp (with the driver overlay), dsh-headless and mmh-headless, under a trial home that already holds the home patch; assert `session-log-deepseek` is disabled in every dump and the U6 rows in web (dsh-web and mmh-web are never launched, and dumping them in a clean home throws unless sync ran or `--from-default-profile` is passed). ## Recommended Handful For BotFleet

## Skip

- **DeepSeek account sign-in, account-funded models, balance UI and hosted billing** (llm-deepseek-account, deepseek-account-platform): they depend on DeepSeek's hosted service.
- **Session-log upload and OTel feedback export:** disable (U1, X14); never adopt.
- **DeepSeek native web search as a BotFleet provider (WEB-5):** it spends a full model turn per query on DeepSeek's hosted server tool; DSH-lane bots and Clutch's web profile already have it through the engine.
- **Perplexity search provider (WEB-4) and a telemetry redaction plugin (PRV-7):** parked.  Perplexity spends a paid model call per query and returns third-party prose; the redactor has no consumer once X14 turns the exporter off, and a missed secret would still upload.
- **The SDK JSON-RPC profile:** weaker than ACP (no cancel or close, process exit abandons a turn).
- **The Typert `/api` HTTP gateway:** an internal client protocol behind a browser-trust fence, with no third-party contract.
- **Basing Clutch's Mac app on the MIT Desktop app:** it embeds its own Host, which conflicts with the always-on pm2 host the iPhone uses.
- **The Python wheel runtime (P4) for now:** PyPI's latest wheel is 0.1.5rc1, and the wheel requires its own DSH_HOME.
- **Falling back from session/resume to session/new on refusal:** contradicts BotFleet's deliberate fail-loud design.
- **The full persisted-type ledger with generated schemas:** overkill for one owner; the light guard in P5 covers the real risk.
- **Vendoring ui-dockkit:** upstream marks its exports unstable; only build a dock if a tab type earns it.
- **Auto review on the headless or ACP paths:** upstream supports it only in a Web profile with the ask policy.
- **Organization-scale process:** weighted-approval PR governance, issue automation, Chinese localisation, brand guidelines (beyond never using DeepSeek marks), product analytics, Windows sandbox ACL work, the website and the Python SDK.
- **Hooks as a merge gate (P17 stays low):** seats on several platforms bypass git hooks, and CI already owns lint and typecheck.
