## Download a released build

Choose your computer below.  Each macOS link always downloads the latest published build from the
[BotFleet Releases page](https://github.com/Simple-With-Us/BotFleet/releases).

| Platform | Recommended package | Notes |
|---|---|---|
| macOS Apple silicon | [Download `.dmg`](https://github.com/Simple-With-Us/BotFleet/releases/latest/download/BotFleet.dmg) | Signed with the BotFleet Developer ID.  Drag to Applications. |
| macOS Intel | [Download `.dmg`](https://github.com/Simple-With-Us/BotFleet/releases/latest/download/BotFleet-intel.dmg) | Same app, built for Intel Macs. |
| Windows x64 | Not published yet | The release workflow builds a per-user installer, but no Windows build has shipped.  Build from source below. |
| Ubuntu 24.04 x64 | Not published yet | The release workflow builds a `.deb` and an AppImage, but no Ubuntu build has shipped.  Build from source below. |

<Callout type="info" title="Updates are manual for now">
  In-app **Check for updates** reads a `latest-mac.yml` feed that the current release does not carry yet.  Until the release workflow publishes a full asset set, install a newer build by downloading it from the releases repository.
</Callout>

## Install an agent CLI

BotFleet needs at least one supported agent engine installed and signed in. Claude and Codex are the most common starting points.

1. Install the CLI from its official provider.
2. Run it once in a terminal and complete sign-in.
3. Restart BotFleet.
4. Open the model picker. Available engines appear normally; unavailable engines explain what is missing.

See [Agent engines](../providers/index.mdx) for the complete list and explicit path overrides.

## Build from source

Requirements: Node.js 24 or newer, pnpm 10.33.0, and at least one authenticated agent CLI.

```bash
git clone https://github.com/Simple-With-Us/BotFleet.git
cd BotFleet
corepack enable
pnpm install --frozen-lockfile
```

Run the harness, web UI, and Electron shell in separate terminals:

```bash
pnpm dev:server
pnpm dev
pnpm dev:desktop
```

## Where data lives

BotFleet stores its application data under `~/.botfleet`. Electron window and browser data use the normal per-platform application data directory.
