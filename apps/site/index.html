A Fleet of Bots, Built on OpenMausBot

BotFleet is a distribution of the open-source OpenMausBot desktop app, extended to run a coordinated fleet of specialized bots on your own Mac.  This page tracks the add-on features BotFleet layers on top of upstream OpenMausBot and how far along each one is.

Chat Bubble & Request ID Copy Controls

Click any user or bot message bubble to instantly copy its text.  Hover for a dedicated copy button with right-click options to copy the Request ID or Message ID for quick logging.

Pull request #5 · Verified in daily use

Usage Telemetry & Central Accounting

Live token consumption (prompt, completion, cache hits) and model costs stream to Usage Monitor (usage.jays.services) with automatic project and repo classification.

Pull request #5 · Live on usage.jays.services

Multi-Repo Channels & Interactive File Links

Channels can attach multiple repositories (e.g. AI Fleet Coordinator + Fleet Ops) with automatic context injection.  Local file links open in default Mac apps with 1 click or reveal in Finder on Option-click.

Pull request #5 · Verified in daily use

Dynamic System Theme & Update Controls

Theme auto-switches between dark and light to match macOS.  Includes update toggle preferences and refined in-app banner controls.

Pull request #5 · Verified in daily use

Beta & In Review Beta

Feature-complete add-ons undergoing active tuning and review.

Native DeepSeek Engine & Pricing Breakdown

Native API and ACP drivers for DeepSeek V4 Flash, V4 Pro, and R1 Reasoner, complete with an in-app model rates and token pricing reference in Settings.

Pull request #5 · Under active test

Multi-Tier Model Fallback Chains

Assign 1st, 2nd, and 3rd choice fallback models to each bot.  When primary engines hit rate limits or downtime, BotFleet degrades down the chain automatically without interrupting work.

Pull request #5 · In review

Mid-Task Crash & Restart Recovery

Interrupted turns and mid-flight tool executions are automatically detected on boot, prompting immediate resumption instead of leaving tasks stuck in an unknown state.

Pull request #5 · In review

Always-On iMessage Relay Daemon

Background relay daemon connecting Messages.app bot group chats to the BotFleet backend with persistent launchd supervision.

Under active test
