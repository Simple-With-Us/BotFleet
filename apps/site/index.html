A host daemon plus LaunchAgents keep bot group chats in Messages.app wired to the BotFleet backend in both directions while the relay is running.

From OpenMausBot

BotFleet is a friendly fork.  The core app still comes from OpenMausBot by Milind Soni and contributors.

github.com/milind-soni/OpenMausBot Upstream source — open this repository for the current OpenMausBot project, including later changes this fork has not pulled.

When we forked, OpenMausBot already shipped:

  • Bring-your-own Claude, Codex, Grok, Cursor, and OpenCode engines on your own logins
  • A local-first harness on 127.0.0.1 with transcripts and keys on disk
  • Per-bot model picker, cloud / Local VM / this-computer, and live screen preview
  • Approval cards, Composio connected apps, and a messaging-app roster
  • Channels, Markdown team import, ElevenLabs voice, and macOS dictation
  • Streaming tool-run chips, an MCP control plane, routines, and webhooks
  • Packaged macOS, Windows, and Ubuntu desktop shells
BotFleet builds on OpenMausBot, an open-source project by Milind Soni and contributors.  BotFleet source lives at github.com/jaywedgeworth22/BotFleet.  iOS companion: public TestFlight.
